Лабораторная работа № 10. Лепендина Анна группа бИД-261. Задание 2 вариант 6. 
Домашнее задание индивидуальный вариант. Условие задачи.
Составьте программу, которая для заданной пользователем фигуры, например (прямоугольника, треугольника, трапеции, квадрата и круга) предлагает меню выбора одной из операций:
1) рассчитать площадь;
2) вывести определение фигуры;
3) нарисовать фигуру.
Фигуры: прямоугольник, треугольник, трапеция, квадрат, круг. Дополнительно: сравнение площадей двух кругов.
